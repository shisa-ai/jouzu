# Jouzu v0.1.4

Jouzu v0.1.4 adds a release-owned extension set, an optional model catalog, and opt-in import from stock Pi configuration.

## Included tools

Core and JA load the same bundled extensions:

- `schedule_prompt` for one-time and recurring prompts;
- `bg_task` for non-blocking shell processes and wakeups;
- `web_fetch` and `batch_web_fetch` for readable HTTP content;
- `tff-fetch_url` and `tff-search_web` for rendered browser access and search;
- code previews for supported tool calls and results;
- `TaskCreate` and related tools for finite task tracking;
- `/goal`, `get_goal`, and `update_goal` for one user-created persistent objective;
- `multiloop_*` for approved measured iteration loops;
- `vcc_recall` and pi-vcc deterministic compaction; and
- `$` skill suggestions through Pi's native autocomplete trigger.

The extension code and its runtime dependencies ship inside `jouzu`; first launch does not assemble this set from npm or Git. Jouzu updates it with application releases. Additional Pi packages remain user-managed and are outside Jouzu's release qualification.

## Other changes

- Add separate first-run consent prompts for importing stock Pi `models.json` and `auth.json`. Both default to no, preserve the source, and never replace an existing Jouzu file.
- Add `jouzu catalog status`, `refresh`, `accept`, `validate`, and `conformance`. With no configured endpoint, Jouzu performs no catalog request and continues using Pi and local model configuration.
- Validate remote catalog JSON with duplicate-key, broken-reference, credential-field, account-scope, and sequence checks. Refresh streams at most 16 MiB, partitions private cache by account, supports ETag validation, quarantines bounded mass changes, and retains the last-known-good document on failure.
- Restore the last Models filter, queue selections made during an active model call, and let repeated `Ctrl+P` presses advance through queued favorites.
- Use replacement Palette presentation on terminals that render inline images above text.
- Add `jouzu-clear-writing` and `jouzu-source-check`; update `jouzu-core` to choose among the active repository, context, web, task, goal, loop, background, and scheduling tools.
- Default Jouzu's isolated settings to quiet startup. `--verbose` still shows Pi's resource inventory.

## Requirements

Jouzu v0.1.4 requires Node.js 22.19 or newer, npm, Git, Bash, and a separately authenticated Pi-supported model provider. Windows requires Git Bash and a UTF-8-capable terminal.

Install from npm:

```bash
npm install --global jouzu@0.1.4
jz doctor
jz
```

Eligible global npm installations can update with:

```bash
jz self-update apply
```

## Limitations

The included extensions run with the user's permissions. Network tools contact the requested sites, and Camoufox may download its browser binary on first browser use. Arbitrary additional Pi packages have their own provenance and platform support.

The v0.1.4 bundled extension set is qualified on Linux and macOS. Native Windows qualification is pending; v0.1.3 is the last release qualified by the full Windows matrix.

The optional catalog supplies metadata; it does not provide model access, authentication, routing, cost, privacy, retention, region, or certification guarantees.

npm is the only functional v0.1 channel. PyPI `jouzu==0.0.1` remains a non-functional reservation.
