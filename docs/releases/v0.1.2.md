# Jouzu v0.1.2

Jouzu v0.1.2 adds the Jouzu Palette Models view and persistent interactive session surfaces, and updates the bundled runtime to qualified Pi 0.84.3.

## Changes

- `/model` and `Ctrl+L` open the Models view without clearing the prompt draft. Recent, Favorite, and All filters search provider/model identity and display names.
- `Enter` selects a model for the session. `Shift+Enter` also stores a user-local project default. Explicit model, scoped-model, and resume/session choices retain precedence.
- Global favorites plus project/global dispatch-based recents remain in local Jouzu state. `Ctrl+P` and its reverse binding cycle available favorites within the effective model scope. Model labels are sanitized before terminal rendering.
- The Prompt Frame, Session Line, and responsive Status Bar preserve Pi editor, autocomplete, cursor, large-paste, history, and IME behavior while showing provider-neutral local facts.
- Jouzu-owned colors map to truecolor, 256-color, 16-color, or plain output according to terminal support.
- `jouzu doctor --json` exposes the human diagnostics as experimental schema 1. The output identifies itself with `"experimental": true`; its structure and identifiers may change before v0.3/v0.4.
- Linked development builds report their UTC build time, source commit, and dirty-worktree state without changing the published package version.
- Pi 0.84.3 is pinned with verified npm integrity and Git provenance, exact Pi TUI peers, zero source deviations, and session-scoped model activation.

## Requirements

Jouzu v0.1.2 requires Node.js 22.19 or newer, npm, Git, Bash, and a separately authenticated Pi-supported model provider. Windows requires Git Bash and a UTF-8-capable terminal.

Install from npm:

```bash
npm install --global jouzu@0.1.2
jz doctor
jz
```

## Limitations

The Models view refreshes Pi's effective model inventory when it opens and keeps cached models available if refresh fails. Project defaults, favorites, and recents are local preferences rather than provider routing, cost, privacy, retention, region, or certification guarantees.

npm is the only functional v0.1 channel. PyPI `jouzu==0.0.1` remains a non-functional reservation.
