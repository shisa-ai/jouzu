# Jouzu v0.2.6

Jouzu v0.2.6 expands `/status`, improves usage and cost reporting, adds `/help` and `/plugins`, and updates the embedded Pi runtime to 1.5.2.

## Session status and usage

- `/status` shows session identity, workspace and Git state, the active model and thinking level, context usage, token usage and cost, running work, and items that need attention with commands to address them. Per-model totals include subagent runs.
- The status bar shows cumulative cache-read share and distinguishes billed, estimated, partial, and unavailable costs. Known zero costs stay visible; unavailable amounts are omitted rather than shown as zero.
- Context usage after compaction is estimated until measured usage becomes available, with `~` marking estimates. Child-agent totals retain their cost source and known partial amounts.

See [Session interface](https://github.com/shisa-ai/jouzu/blob/v0.2.6/docs/interface.md).

## Commands and language

- `/help` opens the localized shortcut overlay used by Ctrl+/. `/plugins` explains Pi package installation and Jouzu customization.
- Completed `/model` commands open Jouzu's model picker, including full-width slash entry.
- Translate `/status` rows, flow help and control notices, thinking labels, and fixed Settings values through the interface catalog. User text, model names, stored settings, and provider errors keep their original content.
- System-prompt guidance follows the tools and features available in the session.

See [Session interface](https://github.com/shisa-ai/jouzu/blob/v0.2.6/docs/interface.md) and [Language](https://github.com/shisa-ai/jouzu/blob/v0.2.6/docs/language.md).

## Reliability

- Print mode waits for accepted asynchronous work and its continuation before printing the final answer and exiting. Cancellation and branch changes stop that wait.
- Compaction preserves references to user requests and later corrections, including image-only requests, so the agent can recall their full text instead of relying only on a shortened summary.
- Bundled llama.cpp requests work with flow control while retaining discovery, authentication, and request checks.
- Shisa sign-in uses the catalog endpoint returned by the signed-in service. Environment API keys and separately saved catalog tokens keep the standard API endpoint.

See [Flow control](https://github.com/shisa-ai/jouzu/blob/v0.2.6/docs/flow-control.md) and [Tools](https://github.com/shisa-ai/jouzu/blob/v0.2.6/docs/tools.md).

## Embedded Pi 1.5.2

The runtime update adds richer Mermaid rendering and the option to fork a session into the current folder when its original folder is gone. It includes fixes for large-file reads and grep context, Windows file matching and clipboard paste, prompt-template quoting, pasted-text restoration, MCP authentication and response limits, and shutdown cleanup.

OpenAI-compatible requests omit an empty `tools` array. If an older proxy requires that field after tool use, set `compat.requiresToolsWithToolHistory: true` for the model in `models.json`. Extension authors overriding remote grep should use `execute()`; custom `GrepOperations.readFile` callbacks no longer supply context lines.

Jouzu keeps prompt-cache warming off by default. Flow-controlled Anthropic requests use complete messages rather than server-side message-thread deltas. The runtime's output budget leaves a proportional reserve for tokenizer differences, reducing avoidable context-limit errors.

See [Pi update review](https://github.com/shisa-ai/jouzu/blob/v0.2.6/docs/PI-UPDATES.md).

## Install or update

```sh
npm install -g jouzu@0.2.6
jz doctor
```

Source builds require **npm 11.13.0 or newer**. `dev-build.sh` checks the version before installing dependencies; npm 11.9 can fail with `EALLOWGIT`. This source-build requirement does not change the published CLI's Node.js minimum of 22.19. See [Development](https://github.com/shisa-ai/jouzu/blob/v0.2.6/docs/development.md).

The signed Windows x64 full installer is `jouzu-win-x64-v0.2.6-setup.exe` in this release's assets. Its publication follows npm publication; check the asset list before downloading.

Jouzu remains beta software. Japanese interface support remains a preview. Native Windows qualification uses Windows Server 2025 and does not establish behavior on every Windows 10/11 configuration.
