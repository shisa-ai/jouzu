# Jouzu v0.1.0

Jouzu v0.1.0 is the first functional npm developer preview of an agentic AI environment built on Pi, with CJK-safe text and path handling.

## Highlights

- Exact qualified Pi 0.84.2 behind the `jouzu` and `jz` commands
- Isolated Jouzu configuration, authentication, package, profile, and session roots
- Safe language-neutral Core fallback and optional JA preview with dry-run planning, conflicts, backups, and automatic reconciliation
- Explicit first-run consent before enabling Japanese-focused response guidance; Core remains the non-interactive and negative-answer fallback
- CJK-safe text and path handling; the JA preview preserves exact code, commands, identifiers, paths, logs, and source errors
- Adaptive Unicode startup presentation and provider-neutral `/status` session summary
- Non-mutating `doctor` diagnostics
- Pi-compatible first-run Jouzu key defaults (`Tab` follow-up, `Ctrl+Up` dequeue) with user-file preservation, semantic planning, conflict-safe apply/reset, backups, and terminal portability notes
- Default pre-TUI automatic updates for real global npm installs, with exact-version SHA-512 verification, installed-runtime smoke, rollback, restart, policy controls, and safe source/local/npx fallback
- Deterministic CJK, encoding, profile, updater, compatibility, and packed-install gates

## Requirements

Jouzu v0.1 requires Node.js 22.19 or newer, npm, Git, Bash, and a separately authenticated Pi-supported model provider. Windows requires Git Bash and a UTF-8-capable terminal; see the repository's Windows prerequisites.

Install from npm after publication:

```bash
npm install --global jouzu@0.1.0
jz doctor
jz
```

## Limitations

npm is the only functional v0.1 channel. PyPI `jouzu==0.0.1` remains a non-functional reservation. This release does not bundle prerequisites, import stock Pi state, provide native installers or standalone archives, operate a hosted model gateway, or make provider privacy, retention, region, routing, or certification guarantees.
