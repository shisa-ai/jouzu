# Jouzu v0.1.6

Jouzu v0.1.6 publishes the complete repository README on npm. The runtime and exact Pi 0.84.4 dependency are unchanged from v0.1.5.

## npm documentation

The npm package README now matches the repository README byte for byte. It includes the full installation, profile, model, catalog, keybinding, updater, diagnostics, platform, and limitation documentation.

Release metadata validation rejects a package README that differs from the repository README. The final publication check also compares the README inside the packed npm artifact before creating the immutable release tag.

## Platform qualification

The bundled extension set is qualified on Linux and macOS with Node 22 and 24. Windows npm installs remain available, but Windows release qualification is paused while package size and updater rollback time are reduced.

## Install

Jouzu v0.1.6 requires Node.js 22.19 or newer, npm, Git, Bash, and a separately authenticated Pi-supported model provider. Windows requires Git Bash and a UTF-8-capable terminal.

```bash
npm install --global jouzu@0.1.6
jz doctor
jz
```

npm is the only functional v0.1 channel. PyPI `jouzu==0.0.1` remains a non-functional reservation.
