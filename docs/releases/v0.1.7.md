# Jouzu v0.1.7

## Features

- **Agents and runs:** `/workflow` lets you configure roles, models, and instructions, then launch, inspect, stop, and resume child agents. Review-only agents use read-only tools and report whether the workspace changed during review.
- **Catalog models:** configured providers can receive additional models and updated capabilities from catalogs. Changes apply to the active session without rewriting `models.json`.
- **Optional TextGuard:** scan skills and web results with a separate TextGuard 1.0.0 installation. Scanning is off by default; see [TextGuard setup](https://github.com/shisa-ai/jouzu/blob/v0.1.7/docs/textguard.md).

## Installation and reliability

- Upgrade the bundled Pi runtime to 0.85.0 and use Pi WebAIO for readable web fetches.
- Install the Camoufox client and browser on the first rendered fetch or search. These downloads require network access and writable Jouzu state. `jz doctor` reports installation status.
- Reduce packaged files, include cross-platform clipboard bindings, and use SQLite prebuilt binaries without a C++ compiler.
- Fix catalog refresh and cancellation, preserve explicit thinking settings and Jouzu terminal titles, and keep updates and diagnostics available when interactive imports fail.
- Correct npm README links and refine the Clear Writing skill to preserve useful structure and sound wording.

## Upgrade

```bash
npm install --global jouzu@0.1.7
jz --version
jz doctor
```

Eligible global installations also update automatically. Node.js 22.19 or newer, npm, Git, Bash, and provider authentication are required. Windows requires Git Bash. Child shell tools run with your OS permissions; they are not a security sandbox.

## Release assets

The attached npm tarball is the same package tested on Linux, macOS, and Windows and published to npm. `SHA256SUMS` records its checksum; `release-manifest.json` identifies its source commit and qualification run. The tarball requires Node.js and npm; it is not a standalone executable.
