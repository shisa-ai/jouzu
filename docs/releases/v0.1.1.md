# Jouzu v0.1.1

Jouzu v0.1.1 changes the queued follow-up shortcut from `Tab` to `Ctrl+Enter`. `Tab` retains Pi's editor autocomplete behavior.

## Changes

- Fresh Jouzu keybinding files use `Ctrl+Enter` for `app.message.followUp` and retain `Ctrl+Up` for `app.message.dequeue`.
- Upgrades back up and replace an exact v0.1.0 `Tab` follow-up entry only when the Jouzu ownership receipt matches it.
- User-owned or modified keybindings remain unchanged. If another editor action claims `Ctrl+Enter`, Jouzu removes its owned `Tab` entry and reports the conflict.

## Requirements

Jouzu v0.1.1 requires Node.js 22.19 or newer, npm, Git, Bash, and a separately authenticated Pi-supported model provider. Windows requires Git Bash and a UTF-8-capable terminal.

Install from npm:

```bash
npm install --global jouzu@0.1.1
jz doctor
jz
```

`Ctrl+Enter` and `Ctrl+Up` require the terminal to report modified keys. Use `jz keybindings plan` to inspect the effective bindings and portability notes.

npm is the only functional v0.1 channel. PyPI `jouzu==0.0.1` remains a non-functional reservation.
