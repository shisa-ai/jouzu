# Jouzu v0.1.3

Jouzu v0.1.3 fixes model-picker routing and makes global favorites the quick-switch list.

## Changes

- `/model` and `Ctrl+L` open the Jouzu Models view even when slash autocomplete is visible or Pi has copied its stock model handler directly into the Prompt Frame.
- Opening Models refreshes Pi's effective model inventory. A failed or timed-out refresh leaves cached models available and shows the failure inside the view.
- `Ctrl+F` toggles membership in one global favorites list. `Ctrl+P` and its reverse binding cycle available favorites within the active context and effective model scope.
- Project favorites and `Alt+F` are removed. `/scoped-models` is removed from Jouzu autocomplete; manual entry explains how to manage favorites.
- Explicit and configured Pi model scopes remain inventory constraints. Favorites outside that inventory are retained but are not selected by quick cycling.
- Prompt drafts, cursor position, collapsed pasted text, extension shortcuts, and explicit editor-history bindings retain precedence across picker and cycle actions.

## Requirements

Jouzu v0.1.3 requires Node.js 22.19 or newer, npm, Git, Bash, and a separately authenticated Pi-supported model provider. Windows requires Git Bash and a UTF-8-capable terminal.

Install from npm:

```bash
npm install --global jouzu@0.1.3
jz doctor
jz
```

Eligible global npm installations can update with:

```bash
jz self-update apply
```

## Limitations

Favorites, project defaults, and recents are local preferences. They do not establish provider routing, cost, privacy, retention, region, or certification guarantees. Quick cycling skips unavailable favorites and models whose advertised context budget cannot hold the active context.

npm is the only functional v0.1 channel. PyPI `jouzu==0.0.1` remains a non-functional reservation.
