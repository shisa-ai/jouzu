# Jouzu v0.2.5

Jouzu v0.2.5 adds catalog token prices to the Models view, simplifies model listings, improves catalog update review, and updates the embedded Pi runtime to 1.5.0.

## Models and prices

- The selected model shows its context window and maximum output together, followed by published catalog prices in USD per million tokens when known rates exist.
- Input, output, cached-input, and cache-write prices are independent: unknown rates are omitted, and explicit zero rates remain visible. Upstream comparison prices are not shown. These reference prices do not change provider billing or session cost accounting.
- Prices align with the model details and wrap on narrow terminals. Rate labels are shorter, with at least two decimal places and additional precision for sub-cent rates.
- Provider labels are muted; context and ratings use regular text. Missing ratings leave blank cells, and a rating column appears only when the unfiltered model inventory contains that rating. Searching does not change which rating columns are present.

See [Models](https://github.com/shisa-ai/jouzu/blob/v0.2.5/docs/models.md).

## Catalog updates

Valid catalog revisions apply automatically, including large additions, removals, and model ID changes. A complete empty catalog that would replace a non-empty one is held for review.

The review dialog shows model counts and offers Accept or Reject; Esc defers the decision. Catalogs marks the source `update held`, and U reopens the review. `jouzu catalog status` reports a change summary and exact accept/reject commands; `jouzu catalog reject` discards a held revision. Non-interactive refreshes provide the accept command.

See [Catalogs](https://github.com/shisa-ai/jouzu/blob/v0.2.5/docs/catalogs.md).

## Embedded Pi 1.5.0

The runtime update includes incremental parsing of streamed tool arguments, cached terminal rendering, context-edit-aware branch summaries, failed-session-write rollback, and provider and terminal fixes. Jouzu retains its flow-control, content-scanning, catalog, and clipboard integrations.

Extension authors should review Pi's tool-schema compatibility change: tool arguments use JSON Schema validation through pi-schema. TypeBox-only refinements, codecs, BigInt/Undefined schemas, and custom TypeBox formats do not apply to tool arguments. Extensions loaded through Pi retain their TypeBox compatibility imports. See the [Pi 1.5.0 release](https://github.com/earendil-works/pi/releases/tag/v1.5.0) and [Jouzu Pi review](https://github.com/shisa-ai/jouzu/blob/v0.2.5/docs/PI-UPDATES.md).

## Install or update

```sh
npm install -g jouzu@0.2.5
jz doctor
```

The signed Windows x64 full installer is `jouzu-win-x64-v0.2.5-setup.exe` in this release's assets. Its publication follows npm publication; check the asset list before downloading.

Jouzu remains beta software. Japanese interface support remains a preview. Native Windows qualification uses Windows Server 2025 and does not establish behavior on every Windows 10/11 configuration.
