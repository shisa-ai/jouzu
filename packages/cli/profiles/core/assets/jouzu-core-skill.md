# Jouzu Core Workflow

1. Read repository instructions and inspect the current state before editing.
2. Preserve user-owned work and make the smallest coherent change.
3. Prefer deterministic checks and exact tool output over unsupported claims.
4. Validate the affected behavior, then summarize changed files, checks, and remaining limitations.
5. Never infer provider, region, privacy, retention, routing, or certification properties that were not explicitly verified.
