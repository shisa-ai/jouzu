# Pinned dependency UI audit partition

This is a bounded source-based ledger of Pi's native terminal UI and the release extension entry points loaded by Jouzu at `fe0cf0878e35236ec9716f5d3ee237fff11c3480` on `jouzu-ja`. **It is not a closed exhaustive semantic audit or a runtime-rendering certification.** Major active panels and state families are traced; extracted fields, mechanically discovered candidates, fallback routes and unresolved boundaries are identified separately.

No product, catalog, dependency or installed source was changed. This partition performed no installation, network request, provider refresh, login, account operation, terminal interaction or broad test suite. Runtime scenarios remain unexecuted.

### Source anchor interpretation

`source_symbol` labels each location before its line number. `implementation:class`, `implementation:function` and `implementation:method` require a unique supported line-start declaration/body shape rather than an earlier import, call or callback. `declaration:initializer` identifies a named variable initializer, not a verified function body. `source-expression` identifies an explicit extraction line. `textual-reference` is only the specified text or a first occurrence when no unique supported declaration was found; it must not be read as an implementation anchor.

`source-anchors.csv` records the matched source line and any earlier caller/textual reference separately. Earlier calls are retained as caller evidence rather than substituted for the implementation. The resolver uses bounded source patterns, not a JavaScript/TypeScript parser or runtime introspection; unsupported or ambiguous syntax remains textual-reference evidence.

## Scope authority and adaptation boundaries

- Pi's exact authority is `upstream/pi.lock.json`: `@earendil-works/pi-coding-agent@1.4.0`, tag/commit recorded there. Installed sibling runtime versions and integrity records are recorded in `packages.csv` against the direct CLI manifest and npm lock.
- Release extension authority is `packages/cli/release-extensions.json`. Each release-owned extension entry point is inventoried rather than inferred from a translation key. Installed source is under `packages/cli/node_modules/`.
- `packages/cli/src/pi-ui-localization.ts` patches selected Pi component prototypes and selected owned widget graphs. It does not globally translate `Text`, every `SettingsList`, every generic extension dialog, every dynamic renderer, status notice or arbitrary payload.
- `packages/session-ui/src/prompt-frame.ts` adapts owned slash descriptions and intercepts `/model` and `/scoped-models` submissions. Native model panels are fallback/conditional routes, not proof that Jouzu normally displays those panels. `/scoped-models` is hidden from normal suggestions.
- The Jouzu UI partition owns Session UI, model-management screens, activity/dashboard formatting and optional browser adapter UI. This dependency partition reads their wiring only to establish ownership, interception and fallback boundaries.
- Native MCP is invoked through Jouzu's deferred MCP wiring. Native codemode extension UI is replaced by the Jouzu override; merely finding its renderer source does not establish an active Jouzu screen.
- `STARTUP-AUDIT.md` and existing startup tests remain narrow prior evidence. Catalog presence and passing fixture tests are not successful startup or traversal evidence.

## High-priority confirmed source-English routes

“Confirmed” here means **implemented English interface text and a traced UI consumer outside the selected adaptation path**, not observed Japanese-runtime English.

1. **Authentication beyond the provider title.** The `/login` auth-method root uses a generic/animated selector. `LoginDialogComponent`, generic auth-select prompts, local provider-auth instructions/progress, copy/open URL hints, logout outcomes and empty-provider messages are not covered by the OAuth title/basic-status patch. Local `pi-ai` source instructions are interface text, not exempt remote service prose. The local OAuth callback HTML has English success/failure headings and `lang="en"`; the branding transform changes logo/color, not language.
2. **Dynamic session/tree UI.** Session scope/sort/filter/name/path/loading/empty/delete/rename/error hints and tree row-kind labels/navigation/filter/fold hints are dynamically rendered outside the narrow title/search/label rewriting. Preserve session names, queries, messages, labels and paths.
3. **Settings composed text and display values.** Model-thinking's composed `Step 1/2 · ...` and `Step 2/2 · ...` do not match standalone-description keys. `currentValue`/`values` are not generally translated; human strings such as `configure`, `none`, configured counts and theme-mode actions must be distinguished from protected technical tokens. Root label translation is not submenu/value completeness.
4. **Extension-owned menus.** `/tasks` root/detail/create/auto decisions and its six-setting panel; `/schedule-prompt` jobs/settings/add flow and widget; `/code-preview-settings` category/submenus and `/code-preview-health`; `/bg` dashboard/results/statuses; `/goal` and `/multiloop` status/actions/durable summary cards; VCC recall framing remain native source UI. Slash-description rewriting does not translate panels or argument completions.
5. **Command/lifecycle notices.** `/reload`, `/export`, `/import`, `/copy`, `/name`, `/session`, `/fork`, `/clone`, `/new`, `/hotkeys`, retry/compaction/abort/cache notices and generic confirmation `Yes`/`No` contain UI outside selected selector wrappers. Generic runtime errors need payload provenance before deciding what to translate.
6. **Jouzu transform-injected dependency UI.** `/bug`'s local draft/review/public-submission confirmation and uncertain-outcome handling; clipboard request/failure and crash-report guidance; background persistence/pattern/log-flush warnings; multiloop blocked/resume notices; task paused/waiting feedback; retained Defuddle diagnostics are explicitly inventoried, not dismissed as build output.
7. **Web-fetch retained diagnostics.** `scripts/webaio-defuddle-transform.mjs` emits the collapsed diagnostic count, expanded `Extraction diagnostics (Defuddle):` / batch heading, request headings, omitted/shortened hints and retained fallback diagnostics into installed `pi-webaio/dist/src/jouzu-extension.js`. The underlying sanitized extractor error is source diagnostic content; the wrapper is interface text.
8. **Shared terminal helpers.** Editor paste markers/scroll overflow text, fullscreen transcript search placeholder/no-match text and selection-copy flashes are dependency-owned UI. Paste markers have parser semantics; changing their visible form must not break expansion or mutate the pasted content.

## Uncertainty and semantic-review blockers

Exhaustive semantic coverage is **not closed by this partition**. This ledger and the combined tracked-source census must agree before claiming completeness.

- The exported HTML viewer semantic inventory is explicitly unfinished, including `dist/core/export-html/template.js`. The bounded terminal-sink scan finds no match in that browser template; this is not exclusion evidence. `files.csv`, `unresolved-candidates.csv` and `validation.json` retain that boundary as unfinished.

- `unresolved-candidates.csv` lists remaining mechanically discovered files. Some are active helper/renderer candidates; others are unselected legacy WebAIO modules or out-of-terminal HTML export code. Their inclusion is not a UI claim. Resolve their call graph and disposition before counting them as covered or excluded.
- Per-tool native fallback renderer strings and every multiloop phase/verifier/task/scheduler tool-result error remain grouped route-scope records, not exhaustive per-state semantic reviews. Disabling previews or a renderer conflict can expose native renderers.
- The scan is not a complete exception/string extractor. Additional wording can propagate from `agent-session`, extension loading, model/auth libraries, image processing, shell execution, filesystem errors and third-party parser/transport libraries without matching the sink pattern. No whole-provider diagnostic expansion was attempted after the main authentication routes were identified.
- Terminal placement of dependency status strings and background/task/scheduler widgets under Jouzu's replacement editor/footer/dashboard needs runtime verification. A dashboard claim can suppress native widgets; an extension custom component is not automatically adapted by Pi-owned-widget marking.
- Native `/model`/`/scoped-models` fallback, startup `--resume`, generic startup trust, official-only experimental first-time setup, native configuration selector API and standalone theme/image selector APIs have different reachability predicates. Source existence alone does not establish a launch route. The first-time setup predicate also requires official package/app/config identity, not merely absent settings.
- API key/environment/account/subscription auth badges and mismatched credential types need deterministic fixtures. Remote provider pages, service-returned prose and model content are not localization defects by default.
- The optional first-use Camoufox runtime is inventoried from its manifest/lock but neither installed nor recursively inspected. Its actual adapter UI belongs to the Jouzu UI partition; upstream tool errors need separate provenance if delegated into that UI.
- Source maps, declarations, duplicate/minified bundles, tests and examples are not exhaustive runtime surface inventories. The source scan excludes nested `node_modules` and does not recursively classify all transitive dependencies.
- There is no runtime screenshot/traversal evidence from this partition, including narrow/CJK rendering, cancellation restoration or destructive confirmations. See `runtime-scenarios.csv` for bounded, no-account probes.

## Content preservation

Preserve user text, names, task descriptions/objectives/prompts, session history, assistant/reasoning/summary Markdown, source code/diffs/files, command identifiers and bindings, paths/URLs/model/provider IDs, credential values, shell output and genuinely remote service error/content. Translate separately owned interface framing only. A local helper/provider's English instruction is not remote payload merely because it lives under a library, `core/`, `scripts/` or `upstream/`.

Do not treat a dynamic `error.message`, resource description or custom renderer payload as confirmed missing UI translation without tracing its origin. Do not copy secrets into audit fixtures or evidence.

## Checks and reproducibility

```bash
python3 -B review/ja-localization/full-ui-audit/dependencies/build-ledger.py
python3 -B review/ja-localization/full-ui-audit/dependencies/test_source_anchors.py
```

The builder reads source/metadata and writes only this audit directory. It does not import or execute runtime modules, run appliers, modify installed sources or contact registries. The source-anchor regression checks cover earlier-call precedence, declaration kinds, ambiguous/unsupported fallbacks, exact expression locations, the affected pinned methods and all generated reviewed `InteractiveMode` method anchors. These are source/structural checks, not UI runtime tests.

Combined audit evidence records a passing existing locale/Palette/doctor/TextGuard/voice test run. That result is not copied into any source row as runtime verification and does not close the blockers above. Existing test paths in rows identify relevant tests; they were not rerun by this dependency partition.
