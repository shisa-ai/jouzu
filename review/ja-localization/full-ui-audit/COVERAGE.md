# Coverage and unfinished audit work

## What is established

- An independent census records **500 tracked first-party production/catalog/profile/tooling candidates**, including files with no recognized UI sink. Every candidate has a file disposition. This is **scope accounting**, not full semantic review.
- The state ledgers identify owned terminal, pinned dependency/extension, launcher/installer and operator-CLI routes. Evidence levels distinguish reviewed families from extracted registrations/settings/auth expressions and mechanical candidates.
- The bounded prior startup probe observed **57 offered slash entries**, including English Labels/TextGuard descriptions, and selected settings/command outputs. Its baseline is [STARTUP-AUDIT.md](../translation-drafts/STARTUP-AUDIT.md).
- `operator-cli/observations.json` contains **40 actual compiled-CLI observations across 20 scenarios**, each in English and Japanese, with isolated temporary homes, stripped provider credentials and expected exit statuses. This is not interactive-terminal traversal.
- `operator-cli/component-observations.json` reproduces the diagnostics constructor default and subagent-widget rendering at widths 48 and 100. It does not demonstrate native placement or a launched subagent.
- Saved existing-test receipts report **456 UI/language-related tests**, **65 launcher/update contract tests**, **76 Session UI tests** and **200 additional settings/model/report tests** passing locally on Windows. These invocation groups may overlap; do not add them into a unique-test total or use them as a translation percentage. Test names are recorded in `test-evidence.json`, `launcher-contract-test-evidence.json` and `terminal-test-evidence.json`.

No product translation, catalog, dependency lock, global setting, real account, installation or updater transaction is changed by this audit.

## Completion rule

This snapshot is suitable as a **full-scope inventory with confirmed gaps and an explicit unfinished-work ledger**, not as an exhaustive source-semantic or runtime sign-off. Close semantic pockets, reconcile registrations, execute reachable state fixtures and document native/auth/external-effect blockers before claiming completeness. Language and layout approval remain separate from all of these checks.

The structural validator deliberately reports `semantic_review_signoff` and `runtime_signoff` as unestablished. No claim of translated percentage, unique-defect total or cross-platform correctness is supported by these records.
